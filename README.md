# 🛒 E-commerce API REST

> ⚠️ **Projeto de estudos**: Este repositório foi criado com fins exclusivamente educacionais, como parte do meu processo de aprendizado em Java e Spring Boot. Todo o código presente aqui é resultado de prática, pesquisa e estudo contínuo.

## 📖 Sobre o projeto

Este projeto consiste em uma API REST de E-commerce desenvolvida para simular o fluxo de compra de uma loja virtual — desde o cadastro de produtos até a finalização de um pedido, passando pela adição de itens ao carrinho de compras.

O objetivo principal foi fixar conceitos de desenvolvimento backend com Java e Spring Boot, aplicando arquitetura em camadas e boas práticas de mercado.

## 🚀 Tecnologias utilizadas

- **Java**
- **Spring Boot**
- **Spring Data JPA**
- **Hibernate**
- **MySQL**
- **JWT (JSON Web Token)** — autenticação baseada em tokens
- **Bean Validation** — validação de dados

## 🏗️ Arquitetura

O projeto segue uma arquitetura em camadas:

- **Controller** — responsável por expor os endpoints da API
- **Service** — contém as regras de negócio da aplicação
- **Repository** — responsável pela comunicação com o banco de dados

## ⚙️ Funcionalidades

- Gerenciamento de produtos
- Gerenciamento de categorias
- Gerenciamento de clientes
- Carrinho de compras
- Pedidos
- Operações CRUD completas
- Validação de dados com Bean Validation
- Tratamento de exceções
- Transações com `@Transactional`
- Autenticação e autorização com JWT
- Relacionamentos entre entidades utilizando JPA

## 💡 Conceitos aplicados

- Orientação a objetos e encapsulamento
- Injeção de dependência
- Boas práticas de organização de código
