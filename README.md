Neste projeto foi desenvolvida uma API REST de E-commerce utilizando Java, Spring Boot, Spring Data JPA, Hibernate, MySQL e JWT (JSON Web Token) para autenticação, seguindo uma arquitetura em camadas (Controller, Service e Repository). Foram implementadas funcionalidades como gerenciamento de produtos, categorias, clientes, carrinho de compras e pedidos, além de operações CRUD, validação de dados com Bean Validation, tratamento de exceções, transações com @Transactional, autenticação baseada em tokens JWT e relacionamentos entre entidades utilizando JPA. O projeto também aplica conceitos de orientação a objetos, encapsulamento, injeção de dependência e boas práticas de organização de código, simulando o fluxo de compra de um e-commerce desde a adição de produtos ao carrinho até a finalização de um pedido.

Durante o desenvolvimento, foram utilizadas ferramentas de Inteligência Artificial, como ChatGPT (OpenAI) e Cursor AI, para apoio no aprendizado, esclarecimento de dúvidas, revisão de código, sugestões de melhorias e resolução de problemas. Todo o código foi compreendido, adaptado e integrado ao projeto de acordo com os objetivos de estudo e desenvolvimento.
